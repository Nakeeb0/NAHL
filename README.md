# NAHL

A fast arena roguelike proof-of-concept game for [PICO-8](https://www.lexaloffle.com/pico-8.php). Control a beyblade to defeat enemies and become stronger through powerups

### ▶ [Play in your browser](https://nakeeb0.github.io/NAHL/)

## Controls

| Key | Action |
| --- | --- |
| Arrow keys | Move |
| Z | Dash (on cooldown, shown by the bar) |
| ← / → then Z or X | Choose a powerup on level-up |

## Running locally

Open `nahl.p8` in PICO-8 (the cart `#include`s the `.lua` source files), or open `docs/index.html` in a browser.

To rebuild the web version after changes:

```
pico8 nahl.p8 -export docs/index.html
```
